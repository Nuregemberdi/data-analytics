# Data Analytics — Learning Repository

Learning data analytics from scratch, from September 2026 to February 2027.
Based in Osh, Kyrgyzstan. Background: mathematics teacher.

**Goal:** become a working data analyst — SQL, Python, statistics, causal
inference, and dashboards — with three portfolio projects built on
Kyrgyz data.

## Portfolio projects

**1. University entrance exam analysis (ORT)**
Which preparation methods actually raise a student's score? Uses data from
my own students. SQL, pandas, and a causal design with a comparison group.

**2. Kyrgyzstan open data**
Full pipeline on public data: collection, cleaning, analysis, dashboard.

**3. Dashboard for a local business in Osh**
A real dashboard built for a real client and a real decision.

Each project includes an explicit **Limitations** section describing what the
data cannot show.
