# 03 — Статистика жана себептүүлүк

**Фаза 3 · 11–14-жума · ~68 саат**

Аналитиктин иши "сан чыгаруу" эмес, **ошол сандын эмнени билдирерин так айтуу**.
Бул фазанын максаты — корреляция менен себептүүлүктү ажырата билүү.

## Жумалар

| Жума | Тема |
|---|---|
| 11 | Сүрөттөөчү статистика, бөлүштүрүүлөр, z-упай, перцентиль, нормалдаштыруу |
| 12 | Тандалма, ишеним аралыгы, t-тест, p-мааниси, эффект өлчөмү |
| 13 | Confounding, selection bias, control group, matching |
| 14 | A/B тест дизайны, кубаттуулук эсеби, difference-in-differences |

13-жума — фазанын өзөгү. Калганы ошого даярдык.

## Эки суроо — рефлекске айландырылат

Кайсы жыйынтыкты укпайын, дароо:

1. **Эмне менен салыштырылды?**
2. **Ал эки топ дагы эмнеси менен айырмаланат?**

Жарнама, жаңылык, изилдөө, отчет — баарына.

## Терминдерди атынан билүү

Бул папкада `terms/` файлы жүрөт: ар бир түшүнүккө **бир беттен өз сөзүм менен**
түшүндүрмө. Атын айта албасам — билбегеним.

- normalization / z-score / percentile
- confounding variable
- selection bias / survivorship bias
- control group / comparison group
- matching
- difference-in-differences
- effect size
- statistical significance vs practical significance
