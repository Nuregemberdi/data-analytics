# 04 — Портфолио долбоорлору

**Фаза 5 · 17–22-жума · ~100 саат**

## Бир эреже: жергиликтүү маалымат

Titanic жана Iris менен он миңдеген адам бирдей портфолио жасайт.
Кыргызстандын маалыматы менен сен жалгызсың — жана бул иш берүүчүгө дароо көрүнөт.

## Үч долбоор

### 1. `ort-analysis/` · 17–18-жума
Өз окуучуларымдын ЖРТ маалыматы. SQL + pandas + статистика + себептүүлүк.

**Суроо:** кайсы даярдык ыкмасы упайды чындап көтөрөт?

> ⚠️ Окуучулардын аты-жөнү жана жеке маалыматы **эч качан** GitHub'ка чыкпайт.
> Чийки маалымат `data/raw/` ичинде калат (`.gitignore` менен жабылган),
> репозиторийге анонимдештирилген үлгү гана жүктөлөт.

### 2. `kg-open-data/` · 19–20-жума
stat.kg жана башка ачык булактардан Кыргызстан боюнча маалымат.
Толук цикл: чогултуу → тазалоо → анализ → дашборд.

### 3. `osh-business/` · 21–22-жума
Оштогу бир бизнеске (дүкөн, кафе, окуу борбору) реалдуу дашборд.
Акысыз болсо да жаса — артында чыныгы адам жана чыныгы чечим турганы
портфолиодогу эң күчтүү нерсе.

## Ар бир долбоордун түзүлүшү

```
project-name/
  README.md          англисче: суроо, метод, жыйынтык, Limitations
  data/
    raw/             чийки маалымат (git'ке чыкпайт)
    clean/           тазаланган
  notebooks/
  sql/
  figures/
```

## `README.md` шаблону (англисче)

```markdown
# Project title

## Question
What I wanted to find out, in one sentence.

## Data
Where the data comes from, what period it covers, how many rows.

## Method
What I did, step by step. Why I chose this approach.

## Results
What I found. Charts here.

## Limitations
What this analysis cannot show. Which data is missing.
Why the result may be wrong.
```

**"Limitations" бөлүмү милдеттүү.** Көбү муну жазбайт — жана дал ошондуктан
аны жазган адам башкача көрүнөт.
